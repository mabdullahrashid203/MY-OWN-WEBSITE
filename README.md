# Abdullah Stores 👕🛍️

A simple and professional clothing store website created using **HTML and CSS**.

## 📌 About the Project

**Abdullah Stores** is a beginner-level frontend practice project designed to build and improve my skills in HTML and CSS.

The website includes a clothing-store layout with a navigation bar, promotional banner, product sections, and footer.

* CSS3
* Font Awesome Icons

## ✨ Features

* Clean navigation bar
* Clothing store promotional banner
* Product display section
* Attractive maroon and white color theme
* Social media icons
* Responsive-friendly structure
* Simple footer section

This project was created for **practice and learning purposes** while improving my frontend development skills.
